# Cinepvq Android Client

This directory is reserved for the upcoming Cinepvq native Android application.

## Planned Architecture & Stack
- **Platform:** Android (Phone, Tablet, Android TV)
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose / Android Jetpack
- **Architecture:** MVVM / Clean Architecture
- **Media Engine:** Media3 / ExoPlayer (HLS, multi-source fallback)
- **Networking:** Ktor / Retrofit + OkHttp
- **Backend / Sync:** Supabase Auth & Database (compatible with Cinepvq Web)

*Development will commence in Phase 5.*
